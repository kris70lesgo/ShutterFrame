# Qodo setup

Qodo is intentionally not an application dependency. A repository administrator
must install and authorize the Qodo GitHub App for this repository, then enable
pull-request reviews in Qodo's dashboard. After that, open feature branches as
pull requests and resolve legitimate Qodo findings before merge.

The included pull-request template records migration-safety impact and the local
verification commands. No Qodo review is claimed active until an administrator
completes the authorization.
